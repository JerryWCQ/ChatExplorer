# ChatExplorer

用文件管理器的方式整理 claude.ai 的对话。

claude.ai 的侧边栏只有一条按时间排列的长列表。当对话积累到上千条（个人 1296 条），找东西、分类、清理都很困难。ChatExplorer 是一个 Edge（Manifest V3）扩展，把这份平铺列表变成类似 Windows 资源管理器的界面：文件夹、快捷方式、多选、拖放、搜索、撤销。

> 非官方项目，与 Anthropic 无关。

## 功能

- **文件夹与快捷方式**：每条对话只有一个真实位置，快捷方式是带可见标记的别名。`Ctrl+C` 复制为快捷方式，`Ctrl+X` 移动
- **叠放**：把若干条对话在原文件夹里视觉上折成一摞（类似 macOS 的 Stacks），可手动叠放，也可按日自动叠放。叠放不是文件夹，不改变对话的实际位置
- **两种视图**：图标视图与详情视图（可拖宽列、按列排序、分组）
- **选择与操作**：框选（含自动滚动、`Ctrl` 追加）、`Shift` 范围选、`Ctrl+A`、方向键、拖放移动
- **搜索**：全量扫描，全角/半角与大小写归一化，同时搜标题、笔记、文件夹名
- **撤销与历史**：每个操作都写入事务日志，可逐步撤销/重做，也可在历史面板里直接跳到任意一步之前（最多保留 1000 步）
- **软删除**：删除只是隐藏，进入「已删除」，彻底删除需要二次确认
- **AI 整理（可选）**：接入你自己配置的 API（支持 Anthropic 与 OpenAI 兼容两种接口格式，包括中转站），让模型阅读对话标题与简介，提出文件夹整理方案并执行。每一批改动是一步撤销，涉及删除一律需要确认，可以逐批回退
- 深浅色主题、中英双语界面、自绘滚动条、尊重 `prefers-reduced-motion`

## 设计原则

1. **claude.ai 只读，永不回写。** 重命名、标记、文件夹、隐藏状态全部只存在本地 IndexedDB，不会改动你的 claude.ai 账号里的任何数据
2. **索引完全本地。** 不使用 AI 整理时，不会向任何第三方发送数据
3. **写入只有一个入口。** 界面可以直接读数据库，但所有写入经过同一个 data port，并通过 BroadcastChannel 通知其他标签页
4. **所有破坏性操作可撤销，所有删除需确认。**

## 关于 AI 整理与隐私

启用 AI 整理后，对话的**标题与简介**会发送到你自己配置的接口地址；对话全文只在模型主动调用读取工具时才会发送。API Key 保存在本地数据库的独立条目里，**不会**包含在设置导出或备份中。网络权限使用可选权限，按域名在你配置时才申请，安装时不要求访问所有网站。

## 安装

需要 Node.js。

```bash
npm install
npm run build
```

然后在 Edge 中：

1. 打开 `edge://extensions`，开启「开发人员模式」
2. 点击「加载解压缩的扩展」，选择项目里的 `dist` 文件夹

开发时常用的检查：

```bash
npm run typecheck
npm test -- --run
```

## 技术栈

TypeScript（`strict` + `noUncheckedIndexedAccess`）、React、Vite、Vitest、IndexedDB。目前有 10 个测试文件、133 个测试用例，覆盖视图模型、撤销日志、同步、Markdown 渲染、AI 整理的权限边界与流式解析，并用脚本化的假 API 端到端测试了整个 AI 循环。

## 项目结构

```
src/
  app/        界面外壳：App、视图、导航树、浮层、框选、AI 面板
  core/       数据层：IndexedDB schema、事务日志与撤销、存储、设置
  claude/     与 claude.ai 的只读同步
  agent/      AI 整理：工具定义、权限范围、请求构造、流式解析、运行循环
  ui/         通用组件：图标、Markdown、格式化、i18n
  showcase/   组件展示页
```

## 做的过程中的一些取舍

- **叠放不是文件夹。** 一开始最容易想到的做法是让「一摞」成为一种容器，但那等于再造一套归档系统：面包屑、级联删除、快捷方式的语义都要重来一遍。最后改成「在对话原本所在的文件夹里把它们折起来」，移动、删除、同步、撤销因此都不需要知道叠放的存在
- **框选卡顿的真正原因。** 1296 个节点下框选很卡，我先后优化了几处，最后定位到根因是每帧两次 `setState` 触发了上千个子节点的重新渲染。解决办法是让框选和拖拽全程直接操作 DOM，只在松手时通知 React 一次
- **「回退」不记成新的日志条目。** 把撤销也记成一个动作会无限递归。改成「日志是一条直线，加一个标记当前位置的游标」，同样能看全部动作、回到某一步之前、取消回退
- **AI 的权限边界用代码强制，不靠提示词。** 模型能读哪些对话、能往哪些文件夹移动，由 `scope.ts` 判定；模型的输出先经过 `planChanges()` 校验才会变成真正的操作

## 现状与局限

- 版本 0.2.0，只在 Edge 上测试
- AI 整理已用假 API 完整验证，**尚未在真实官方接口与真实中转站上做充分测试**，尤其是中转站的流式格式与工具调用兼容性；在上千条对话上的整理质量与 token 花费也还没有评估
- 尚未实现：自由布局视图、备份导入（目前只有导出）、水平滚动条
